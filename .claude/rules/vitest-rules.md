# 単体テスト規約（Vitest）
* **テスト配置**: テストファイルは対象ソースコードと同じディレクトリに `[ファイル名].test.ts` または `[ファイル名].spec.ts` の形式で配置してください。
* **擬似モック（Mocking）の活用**: 外部API通信（Axios/Fetch）やファイルシステム（fs）に依存する処理のテストでは、必ずモック（`vi.mock()` 等）を使用し、実際の外部環境に依存しない独立したテストにしてください。
* **テストの網羅性**: 正常系だけでなく、APIエラー（429レートリミット、500サーバーエラー）や、パース時の異常データ入力に対する異常系のテストケースを必ず含めてください。
