# テンプレートリファレンス

Tejun.ts の出力（HTML・Excel）の見た目を決めるテンプレートの書き方です。使い方は [README](../README.md) を参照してください。

テンプレートの中に `{{変数名}}` と書くと、手順書の内容に置き換わります。変数はHTMLとExcelで共通です。

Markdownの要素は、その行の先頭に書く記号で指定します。

| 記号 | Markdownの要素 |
| --- | --- |
| `#` 〜 `######` | 見出し |
| `>` | 引用 |
| `-` | 箇条書きの項目（Markdownの `*` / `+` も含みます） |
| `1.` | 番号付きリストの項目 |
| ```` ``` ```` | コードブロック |

表と、`*` や `` ` `` などの行の途中に書く記法は対象外です。

## 文書全体の変数

| 変数 | 内容 |
| --- | --- |
| `{{meta.title}}` | 文書のタイトル（Front Matterの `title`、なければH1） |
| `{{meta.date}}` | 作成日 |
| `{{meta.update}}` | 更新日（未指定なら空） |
| `{{meta.キー名}}` | Front Matterに書いた任意の項目（例: `{{meta.author}}`）。未指定なら空 |
| `{{root.body}}` | 最初の見出しより前に書いた本文（最初の引用まで）。H1を書かずにFront Matterの `title` だけで始める手順書の前文に使います |

## 要素の変数

| 変数 | 内容 |
| --- | --- |
| `{{記号}}` | 見出しは見出しの文字列、それ以外は要素の内容（例: `{{##}}` `{{###}}` `{{>}}` `{{-}}`） |
| `{{記号.body}}` | 見出しの直後から、最初の引用までの本文（例: `{{#.body}}` は概要文、`{{###.body}}` は操作手順） |
| `{{記号.index}}` | 連番（1から）。見出しは文書全体を通した連番、それ以外は同じ見出し・項目の中での連番 |
| `{{記号.first}}` | Excelの行ループで、その要素が前の行と別の要素なら `1`、同じ要素なら空。`{{#if ##.first}}{{##}}{{/if}}` と書くと、大項目を最初の行にだけ出力する（行ループの外側・HTMLでは常に `1`） |
| `{{記号.記号}}` | 左の要素の中の右の要素（例: `{{###.>}}` は手順の最初の引用＝期待される結果） |

記号が指す要素は、次の順で探します。

1. 一番内側の `{{#each}}` で繰り返し中の要素と、それを含む要素（`{{#each ### steps}}` の中の `{{##}}` はその手順の大項目）
2. 見つからなければ、繰り返し中の要素の中で最初の要素（`{{#each ### steps}}` の中の `{{>}}` はその手順の最初の引用）

`{{#each}}` の外側では、Markdownファイルで**最初に出てくる**その記号の行が該当します（見出しの階層は関係ありません）。たとえば `{{#}}` は最初のH1、`{{>}}` は最初の引用、`{{###}}` は最初の `###` です。

## ループと条件分岐

```text
{{#each ## steps}}                   大項目（##）ごとに繰り返す
  {{##}}
  {{#each ### steps}}                その大項目の手順（###）ごとに繰り返す
    {{##.index}}-{{###.index}} {{###}}
    {{###.body}}
    {{>}}
    <ul>{{#each - steps}}<li>{{-}}</li>{{/each}}</ul>   手順の中の箇条書きの項目ごとに繰り返す
  {{/each}}
{{/each}}

{{#each ### steps}}...{{/each}}       全手順を大項目で分けずに繰り返す
{{#if meta.author}}作成者: {{meta.author}}{{/if}}   値が空でないときだけ出力する
{{#if >}}...{{/if}}                   引用があるときだけ出力する
```

- `{{#each 記号 steps}}` は、繰り返し中の要素（外側では文書全体）の中にある、その記号の要素ごとに繰り返します。入れ子の箇条書きは、外側の項目の中でもう一度 `{{#each - steps}}` を使うと繰り返せます。
- `{{h1}}` `{{h3.blockquote}}` `{{#each h2 steps}}` `{{category}}` などの以前の書き方は使えません。`{{#each}}` / `{{#if}}` に以前の書き方が残っているとエラーになり、変数はそのまま出力されます。

## HTMLテンプレート

[templates/default.html](../templates/default.html) を元に作るのが簡単です。

- 見出し以外の要素（`{{>}}` `{{-}}` `{{1.}}` ```` {{```}} ````）と `{{記号.body}}` は、MarkdownをHTMLに変換した結果がそのまま入ります。
- 見出しの文字列・連番・`{{meta.キー名}}` は、HTMLエスケープされて入ります。
- HTML専用の変数として、`${title}` / `${date}` / `${update}`（`{{meta.title}}` などと同じ値）、`${markdown}`（Markdown全文をHTMLにしたもの）、`${overview}`（概要文をHTMLにしたもの）があります。

## Excelテンプレート

[templates/default.xlsx](../templates/default.xlsx) を元に作るのが簡単です。読み込まれるのは最初のシートだけです。

- **行ループ:** `{{#each 記号 steps}}` と `{{/each}}` を別々のセルに書いた（または `{{/each}}` を省略した）行が、その要素の数だけ複製されます。書式（フォント・塗りつぶし・罫線・配置）も各行に引き継がれます。
  - 例: A列に `{{#each ## steps}}`、B列に `{{#each ### steps}}`、最後の列に `{{/each}}{{/each}}` と書くと、手順（`###`）1つが1行になり、各行で `{{##}}` `{{###}}` `{{>}}` などが使えます。
  - 期待される結果（手順の最初の引用）の中の最初の画像が、その行に貼り付けられます。
- **セル内のループ:** `{{#each - steps}}・{{-}}{{/each}}` のように1つのセルの中で閉じたループは、そのセルの中で繰り返します。
- **それ以外の行:** タイトルや日付などの文書全体の変数を使えます。
- **セルの値:** HTMLタグを取り除いたテキストが入ります。番号付きリストには `1.` `2.` … の番号が付きます。
- **書式付きのセル:** セル内で一部だけフォントを変えた（リッチテキストの）セルでも、変数は置き換わります。ただし、変数を含むセルは置き換え後にセル全体が同じ書式になります。
- **行ループの行の高さ:**
  - テンプレートの行ループの行に高さが設定されていれば、その高さで固定されます。
  - 設定されていなければ、Excelが内容に合わせて自動調整します（既定テンプレートはこちらです）。
  - Excelでテンプレートを編集して保存すると、行に高さが記録されて固定の高さになることがあります。
  - 画像を貼り付ける行は、常に固定の高さになります。
